# ЧистоГрад — лендинг клининговой компании в Челябинске

Готовый адаптивный статический сайт: HTML + CSS + JavaScript без сборки и внешних зависимостей. Шрифты и изображения лежат локально, поэтому сайт можно открыть даже напрямую через `index.html`.

## Как запустить

```bash
cd /Users/kirillspynu/Desktop/DeepHarness
python3 -m http.server 4173
```

Откройте `http://127.0.0.1:4173/`.

## Что внутри

- **Первый экран** с оффером, рейтингом, ключевыми преимуществами и фотографией.
- **Услуги** — 6 карточек с ценами и переходом к заявке.
- **Онлайн-калькулятор** — тип помещения, площадь, тип уборки и допуслуги; цена пересчитывается мгновенно, итог подставляется в модальную заявку.
- **Блок преимуществ, процесс работы, отзывы, FAQ**.
- **Форма заявки** с маской телефона, валидацией и экраном успеха.
- **Мобильное меню**, фиксированная нижняя панель действий, модальное окно, плавные появления секций.
- **SEO**: Open Graph, LocalBusiness и FAQPage JSON-LD, `robots.txt`, `sitemap.xml`, отдельная страница политики конфиденциальности.
- **Доступность**: skip-link, focus-visible, aria-атрибуты, управление фокусом в модалке и меню, поддержка `prefers-reduced-motion`.

## Структура

```text
index.html          — главная страница
privacy.html        — политика конфиденциальности
styles.css          — все стили и адаптив
script.js           — калькулятор, формы, меню, модалка, анимации
assets/
  fonts/            — локальные Onest, Unbounded, Playfair Display
  images/           — оптимизированные WebP-фотографии и OG-обложка
  favicon.svg
  apple-touch-icon.png
robots.txt
sitemap.xml
```

## Важно перед публикацией

1. **Замените контактные данные.** Телефон, адрес, email, Telegram и WhatsApp сейчас демонстрационные. Они встречаются в `index.html`, `privacy.html` и JSON-LD.
2. **Замените отзывы, рейтинг и цифры** на реальные. Сейчас это контент-заглушки для презентации дизайна.
3. **Проверьте цены и состав услуг** — тарифы в карточках и калькуляторе должны соответствовать вашей реальной сетке.
4. **Подключите приём заявок.** Формы сейчас работают в демо-режиме: после отправки показывается экран успеха, а данные сохраняются только в `localStorage` браузера. Для реальных заявок добавьте запрос на ваш backend/CRM в функции `handleMainForm()` и `handleModalForm()` в `script.js`.
5. **Обновите домен** в canonical, Open Graph, `robots.txt` и `sitemap.xml`. Сейчас сайт опубликован на GitHub Pages по адресу `https://wialux12.github.io/chistograd-landing/`; при подключении своего домена замените этот адрес.
6. **Проверьте политику конфиденциальности** с юристом под фактическую компанию и способы обработки данных.
